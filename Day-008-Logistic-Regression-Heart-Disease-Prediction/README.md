# ❤️ Day 008 - Heart Disease Prediction using Logistic Regression

Welcome to **Day 008 of 100 DAYS OF ML CHALLENGE 🚀**

This project uses **Logistic Regression** to predict the likelihood of coronary heart disease within the next 10 years.

---

## 📌 Project Overview

This is a **binary classification** project using the `Heart_Disease.csv` dataset.

The model predicts the target variable:

`TenYearCHD`

- `0` → No coronary heart disease within 10 years
- `1` → Coronary heart disease within 10 years

---

## 🎯 Objective

The objective of this project is to build a Machine Learning model that predicts the likelihood of coronary heart disease based on patient-related features.

---

## 📂 Dataset

**Dataset:** `Heart_Disease.csv`

The dataset contains patient-related information used to predict the `TenYearCHD` outcome.

---
