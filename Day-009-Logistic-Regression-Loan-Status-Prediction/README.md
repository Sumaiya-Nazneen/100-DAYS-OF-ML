# 🏦 Day 009 - Loan Status Prediction using Logistic Regression

Welcome to **Day 009 of 100 DAYS OF ML CHALLENGE 🚀**

This project uses **Logistic Regression** to predict loan status based on applicant and loan-related information.

---

## 📌 Project Overview

Loan Status Prediction is a **binary classification** problem.

The model predicts the `loan_status` of a loan application.

The project uses Logistic Regression along with data preprocessing techniques such as:

- Feature Scaling
- One-Hot Encoding
- Train-Test Split

---

## 🎯 Objective

The objective of this project is to build a Machine Learning classification model that can predict whether a loan application is approved or not based on the available applicant and loan information.
