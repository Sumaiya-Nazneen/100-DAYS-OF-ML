# 🚀 XGBoost Machine Learning

This repository contains my hands-on learning and implementation of **XGBoost (Extreme Gradient Boosting)**, a powerful and widely used Machine Learning algorithm.

## 📌 What is XGBoost?

**XGBoost** stands for **Extreme Gradient Boosting**.

It is a **boosting algorithm** based on decision trees. It builds multiple trees sequentially, where each new tree tries to correct the errors made by the previous trees.

### 🔄 How XGBoost Works

```text
Dataset
   ↓
First Decision Tree
   ↓
Find Errors
   ↓
Next Decision Tree
   ↓
Correct Previous Errors
   ↓
Repeat
   ↓
Final Prediction
```
