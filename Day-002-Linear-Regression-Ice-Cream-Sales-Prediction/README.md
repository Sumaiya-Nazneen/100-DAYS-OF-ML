# 🍦 Day 02 - Ice Cream Sales Prediction using Linear Regression

## 📌 Overview

This project is part of my **100 Days ML Challenge**, where I build and document Machine Learning projects consistently.

In this project, I use **Simple Linear Regression** to analyze the relationship between **temperature** and **ice cream profits** and build a model that predicts ice cream profits based on temperature.

---

## 🎯 Objective

The objective of this project is to understand how temperature affects ice cream profits and use Linear Regression to make predictions.

---

## 📂 Dataset

**Dataset:** `Ice Cream Sales - temperatures.csv`

The dataset contains temperature observations along with the corresponding ice cream profits.

### Features

| Feature | Description |
|---|---|
| `Temperature` | Temperature recorded for the day |
| `Ice Cream Profits` | Ice cream profits corresponding to the temperature |

### Target Variable

`Ice Cream Profits`

---

## 🤖 Machine Learning Algorithm

### Simple Linear Regression

Linear Regression is used to model the relationship between the independent variable (**Temperature**) and the dependent variable (**Ice Cream Profits**).

The model learns a linear relationship from the training data and uses it to predict profits for new temperature values.
