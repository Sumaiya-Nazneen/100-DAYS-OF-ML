# 🏠 Day 004 - House Price Prediction using Multiple Linear Regression

Welcome to **Day 004 of 100 DAYS OF ML 🚀**

This project implements **Multiple Linear Regression** to predict house prices using multiple features related to a property.

---

## 📌 Project Overview

House prices are influenced by multiple factors such as property size, number of rooms, location, and other property characteristics.

In this project, **Multiple Linear Regression** is used to learn the relationship between multiple independent variables and the house price.

### Input Features

Multiple property-related features are used as inputs.

### Target Variable

**House Price**

---

## 🎯 Objective

The objective of this project is to build a Machine Learning model that can predict house prices based on multiple property features.

---

## 📂 Dataset

**Dataset:** House Price Dataset

The dataset contains information about residential properties and their corresponding prices.

Depending on the dataset used, features may include:

* Area / Square Footage
* Number of Bedrooms
* Number of Bathrooms
* Number of Floors
* Property Age
* Location
* Other House Characteristics
* Price

---

## 🤖 Machine Learning Algorithm

### Multiple Linear Regression

Multiple Linear Regression is a supervised learning algorithm used to predict a continuous target variable using multiple independent variables.

The model learns the relationship between property features and house prices.
