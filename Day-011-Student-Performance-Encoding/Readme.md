# 🎓 Day 011 - Student Performance Prediction using Encoders

Welcome to **Day 011 of my 100 DAYS OF ML CHALLENGE 🚀**

This project focuses on **Student Performance Prediction** and demonstrates how categorical student information can be converted into numerical data using **encoding techniques** for Machine Learning.

---

## 📌 Project Overview

Machine Learning algorithms generally work with numerical data. However, real-world datasets often contain categorical information such as student characteristics, educational background, study-related information, and other categorical attributes.

In this project, encoding techniques are used to transform categorical data into numerical representations so that the data can be used effectively for Machine Learning.

---

## 🎯 Objective

The main objectives of this project are:

- Understand categorical data
- Identify categorical features
- Apply encoding techniques
- Convert categorical values into numerical values
- Prepare student data for Machine Learning
- Build a student performance prediction model
- Evaluate the model

---

## 📂 Dataset

The project uses a **Student Performance Dataset** containing information related to students and their academic performance.

The dataset includes a combination of categorical and numerical features.

Categorical features need to be encoded before being provided to Machine Learning algorithms.

---
