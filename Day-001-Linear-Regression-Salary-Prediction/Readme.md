# 💼 Day 01 - Salary Prediction using Linear Regression

## 📌 Overview

This project demonstrates **Simple Linear Regression** by predicting an employee's salary based on their years of experience. It is the first project in my **ML-Every-Day** journey.

---

## 🎯 Problem Statement

Predict an employee's salary using **Years of Experience** as the independent variable and **Salary** as the dependent variable.

---

## 📂 Dataset

**File:** `Salary_Data.csv`

| Feature | Description |
|---------|-------------|
| YearsExperience | Employee's years of experience |
| Salary | Employee's annual salary |

---
