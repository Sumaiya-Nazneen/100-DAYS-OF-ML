# Day 23: SVM Mushroom Classification 🍄

## 📌 Overview
This project uses a Support Vector Machine (SVM) to classify mushrooms as edible or poisonous based on their physical characteristics.

## 🎯 Objective
- Understand the Support Vector Machine algorithm.
- Perform classification using a real-world dataset.
- Learn how to preprocess categorical data.
- Evaluate a machine learning classification model.

## 📂 Dataset
**Dataset:** `mushrooms.csv`

- Total records: 8,124
- Total columns: 23
- Target column: `class`

Target labels:
- `e` – Edible
- `p` – Poisonous

The dataset contains mushroom features such as cap shape, cap color, odor, gill color, and habitat.

## ⚙️ Algorithm Used
**Support Vector Machine (SVM)**

SVM is a supervised machine learning algorithm that finds a decision boundary to separate different classes.

## 🔄 Workflow
1. Import the required Python libraries.
2. Load and explore the mushroom dataset.
3. Check for missing values and duplicate records.
4. Separate the features and target variable.
5. Encode categorical features into numerical values.
6. Split the dataset into training and testing sets.
7. Train the SVM classifier.
8. Predict whether mushrooms are edible or poisonous.
9. Evaluate the model using classification metrics.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Support Vector Machine (SVM)

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report

## 💡 Key Learnings
- Understanding Support Vector Machines.
- Handling categorical data.
- Preparing data for machine learning.
- Training a classification model.
- Evaluating model performance.

## ✅ Conclusion
This project demonstrates how SVM can be used to classify mushrooms based on their characteristics and distinguish between edible and poisonous categories.
