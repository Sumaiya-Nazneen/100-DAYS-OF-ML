# 💎 Day 013 - Diamond Price Prediction using Random Forest Regression

Welcome to **Day 013 of my 100 DAYS OF ML CHALLENGE 🚀**

This project focuses on predicting the **price of diamonds** using the **Random Forest Regression** algorithm.

The project demonstrates how Machine Learning can be used to predict a continuous numerical value based on multiple diamond characteristics.

---

## 📌 Project Overview

Diamond price prediction is a **Regression problem** because the target variable, `price`, is a continuous numerical value.

In this project, a **Random Forest Regressor** is used to learn the relationship between different diamond features and their prices.

The project also demonstrates:

- One-Hot Encoding
- ColumnTransformer
- Machine Learning Pipeline
- Train-Test Split
- Random Forest Regression
- Model Evaluation
- Single Prediction

---

## 🎯 Objective

The main objective of this project is to build a Machine Learning model that can predict the price of a diamond based on its characteristics.

The model learns patterns from the training data and predicts prices for unseen diamond records.
